# 真实教务课表样本采集与脱敏指南

为确保首版教务导入解析精准可靠，首批适配采用**「真样本驱动 + 单元测试回归」**方式，而非盲猜 DOM 结构。

## 如何采集「已渲染」的课表表格

> 不要使用「右键 → 查看网页源代码」，因为现代教务系统（如正方新版、强智等）往往通过前端脚本或同源 `iframe` 动态填充课表，静态源码里通常没有课程数据。

1. 在电脑浏览器登录学校教务系统，打开你的「个人课表」页面，确认课表已经完整显示。
2. 在课表网格上点击**右键 → 检查（Inspect）**，打开开发者工具的 `Elements`（元素）面板。
3. 向上找到包裹整张课表的 `<table>` 元素（或其外层容器 `<div>`）。
4. 在该元素上右键 → **Copy → Copy outerHTML**。
5. 将内容保存到一个本地文本文件，例如 `samples/raw-school-timetable.html`（该命名已被 `.gitignore` 忽略，不会被提交）。

## 脱敏清单（发给我之前请检查）

在把样本提供给我用于编写解析器之前，请删除或替换以下个人敏感信息：

- [ ] **姓名、学号、班级名、学院/专业**（替换为 `张三`、`2026000001` 等）
- [ ] **Cookie、Token、URL 里的学号或 session 参数**（如 `xh=...`、`jsessionid=...`）
- [ ] **若包含授课教师真实姓名或私人备注**，也可按需替换为 `王老师`、`李老师`
- [ ] **保留以下结构信息**（解析器需要依赖它们）：
  - `<table>` / `<tr>` / `<td>` 的标签层级、`class`、`id`、`rowspan`、`colspan`
  - 节次列、星期表头
  - 典型的课程单元格文本格式（**强烈建议保留至少 1 个单周或双周课、1 个多节课连上、以及 1 个同一格内有两门课叠放的例子**）

## 替代提供方式

如果暂时不方便提取 HTML，也可以：
- 告知学校使用的教务系统类型（例如：新版正方 `jwglxt`、旧版正方、强智、树维、青果、URP 等）并复制 **2~3 个典型课表单元格的原始文字**；
- 或者先不提供学校样本，由我先基于一份标准脱敏样例完成首版全流程，后续你随时把真实样本放进来追加专属适配器。
