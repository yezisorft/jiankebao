## 一、项目总结与核心成果

### 1. 项目定位
「简课表查看」是一个**零后端、零登录、零运行时第三方依赖、纯静态离线优先**的个人课表 PWA 工具，面向高校日常查课与临时调停课管理（首批深度适配正方新版教务 `jwglxt V-9.0` 表格与每节 40 分钟的 13 节作息体系）。

### 2. 核心架构与安全特性
1. **三端同源课次引擎**（`src/js/engine.js`）：「今日视图」「周课表视图」与「`.ics` 系统日历导出」严格共用同一套实际课次解析引擎，单双周、非连续周、临时停课、改教室、跨天调课、单次补课在三处展示与导出 100% 一致。
2. **完整教师姓名保真**：所有视图（周课表卡片、今日时间轴、课程详情弹窗、导入预览、`.ics` 日历）均原样保留完整教师姓名（含多位联合授课教师），绝不截断或脱敏。
3. **纯文本隔离 HTML 解析器**（`src/js/html-inert-dom.js`、`src/js/importers.js`）：不调用浏览器 `DOMParser`、不执行 `<script>`、不触发 `<img>/<link>` 等外部子资源网络请求，Node 与全平台浏览器解析结果完全一致；导入流程统一走「解析 → 校验 → 纯文本预览 → 覆盖前自动存快照 → 确认保存」。
4. **数据安全与防误删保障**（`src/js/model.js`、`src/js/storage.js`）：
   - 全写入入口统一强制配额校验（最高 200 门课 / 600 条时段 / 1000 条例外），超限时拒绝写入绝不静默挤掉已有课程；
   - Web Locks 跨标签页排他串行写入 + 修订号冲突检测，防多窗口静默覆盖；
   - 作息表缩短前自动检测超界课程与例外并拦截，自动扩展作息若当日剩余时间超过 `23:59` 则中止写入并保住原有作息与原课表；
   - 完整 JSON / 导入码覆盖恢复按唯一 `(courseId, ruleId)` 保真，保留全部独立规则与对应调停课例外；
   - 严格区分「键不存在 / 读取异常 / JSON 损坏」，读错或损坏时中止覆盖并支持「导出损坏原文 (.txt)」后显式修复；
   - 同源子路径存储与 Service Worker 缓存双隔离，并提供可断点续传的旧版路径数据/快照恢复。
5. **自动化内容哈希离线缓存**（`scripts/build-release.mjs`、`src/sw.js`）：
   - 打包脚本自动扫描 17 项发布资源并计算 SHA-256 短哈希写入 `sw.js`，线上更新后手机端自动弹出更新提示；
   - 配备全出血不透明 iOS 桌面图标（`apple-touch-icon.png` 180×180、`icon-192.png`、`icon-512.png`），消除 iOS 圆角黑边。
