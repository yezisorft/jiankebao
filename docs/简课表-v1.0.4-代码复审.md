## 优先修复的两处问题

### 1. [P1] 合并一门较晚的课，会同时移除已有晚课

**Edge 发布包实测。** 原课表有 14 节作息，第 14 节已排「晚课」。粘贴包含第 17 节「实验课」的教务表格，选择「合并到当前课表」并保留默认的自动扩展。预览一处显示「本次写入 1」「跳过 0」，另一处显示「确认后库内 0 个时段」。点击确认后，作息从 14 节退回 13 节，「晚课」与「实验课」都只剩课程名称，周课表中均无排课。合并前快照仍保有原晚课，可以撤回。

**原因及修改建议。** 自动排作息时连续把晚间开始时间限制为 23:10，生成了相互重叠的时段。导入器先按扩展后的节数接纳课程，最后的规整步骤遇到无效作息又改用默认 13 节。应在生成候选作息后立即校验。如果当日剩余时间不足，应停止此次合并，提示用户手动作息。合并保存前校验原有规则全部保留，预览的写入数从最终课表差异计算。

定位：`src/js/importers.js:580、629、900`，`src/js/model.js:643`，`src/js/app.js:1739`。验收时使用 14 节已有晚课合并第 17 节课程，结果应为成功保留两课，或明确拒绝且原课表完整。

### 2. [P1] 恢复完整 JSON 备份会把两条不同规则合成一条，导致实际日期少课

**发布模块实测。** 一门实验课有两条独立规则，名义上都在前两周周一同一时段上课。第一条在第一周停课，第二条在第二周停课，因此两个周一都应各有一节。用本程序的 JSON 格式序列化，再选择「覆盖当前课表」并勾选恢复例外。预览把第二条规则列为重复。用今日视图共用的课次引擎核对，9 月 7 日从 1 节变为 0 节，9 月 14 日仍为 1 节。两条停课记录只恢复了一条。

**原因及修改建议。** 去重只比较课名、星期、节次、周次、地点和教师。完整备份中每条规则已有独立标识，停课、改课也引用该标识。完整恢复应保留已通过校验的课程 ID、规则 ID 和例外引用，把按显示字段去重留给无稳定标识的教务表格。验收应比较恢复前后整学期按日展开的课次及关联例外。

定位：`src/js/importers.js:547、694、880`，`src/js/engine.js:80`。导入码恢复也进入同一备份预览路径。

## 本次确认有效的修复

- 运行项目全量测试 `node --test tests/*.test.mjs`，**30/30 通过**。源码计算出的发布版本与 ZIP 一致。ZIP 内 17 个文件逐一与 `dist/site` 及 `src` 对应文件比对，字节一致，CRC 检查通过。当前 Git 基线为 `bd1a276`，审查对象包含其后尚未提交的工作区修改。
- **子路径原址升级。** 在临时 Edge 配置中用 v1.0.2 保存 11 门课，在同一地址切换到当前 ZIP。点击「恢复旧版课表到当前路径」后，新路径显示 11 门，旧键仍保有 11 门。关闭临时静态服务后，重新导航到此地址仍能离线打开并读到 11 门。
- **作息缩短保护。** 在设置页把已有第 14 节晚课的课表切为 13 节模板，界面列出受影响课程并阻止缩短。保存数据仍为 14 节、1 条晚课。这与上文第 1 项走的是不同入口。
- **多标签覆盖与撤回。** 在一个标签页保留导入预览，另一页保存新学期名。前一页确认时出现冲突提示，明确选择强制覆盖后，快照含后一页刚保存的学期名。主写入路径已采用 Web Locks。缺少该 API 的环境使用页面内队列，跨窗口保障仍取决于所处环境。

## 可行性、安全与验收范围

就这份发布包而言，纯静态 PWA 适合个人离线课表。导入的 HTML 经自定义文本解析器读取，预览把课程字段创建为文本节点。审查到的运行时代码中未发现课表上传接口或第三方统计请求。导入码与分享链接可由持有人解码，界面已提示这一隐私边界。相关实现见 `src/js/html-inert-dom.js:218`、`src/js/app.js:92、1437`、`src/js/transfer.js:202`。

此版已有正方已渲染表格、通用表格、JSON 和导入码入口，以及系统日历导出。CSV 与 ICS 文件导入在 README 中列为后续版本。iPhone 主屏幕离线冷启动、离线编辑后重启保留，以及系统日历提醒，仍需使用真实 iPhone 在可信 HTTPS 地址验收。本轮浏览器验证使用隔离的桌面 Edge 和临时课表。

下一版优先增加两条端到端回归：合并晚课后原规则完整，完整备份恢复后逐日课次相同。两条都通过，再用同一发布包进行 iPhone 验收。
